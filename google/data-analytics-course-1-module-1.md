# Google Data Analytics — Course 1, Module 1: Introducing Data Analytics & Analytical Thinking

**Platform:** Coursera (Google Data Analytics) | **Studied:** Aug 2026 | **Source:** module 1 readings

## 🎯 What this module is about (one sentence)

What data analysis actually is, the six-step process analysts follow (ask, prepare, process,
analyze, share, act), and the five analytical skills you already have — even if you've never
called them that.

## 🔑 Key Concepts

| Concept | Plain-English meaning | Sue's payroll translation |
|---|---|---|
| **Data** | A collection of facts | Timesheets, pay rates, deduction elections — the raw facts before you do anything with them. |
| **Data analysis** | Collecting, transforming, and organizing data to draw conclusions, make predictions, and drive decisions | Every quarter-end reconciliation you've ever done: gather the numbers, tie them out, explain the variance, recommend the fix. |
| **Data analytics** | The science of data — the whole field | The umbrella term, the way "accounting" covers AP, AR, payroll, and audit. |
| **Data-driven decision-making** | Using facts (not hunches) to guide business strategy | Approving overtime budgets based on actual hours trends instead of a manager's "feeling" that the team is stretched. |
| **The six steps: Ask → Prepare → Process → Analyze → Share → Act** | The standard workflow for any analysis project | Your year-end W-2 cycle: clarify requirements, pull the data, scrub the errors, reconcile, distribute, then file corrections. Same rhythm. |
| **Analytical thinking** | Identifying and defining a problem, then solving it with data in an organized, step-by-step way | Tracing a paycheck discrepancy: define what's wrong, isolate the pay period, check each input, fix the cause. |
| **Root cause / Five Whys** | The real reason a problem happens; ask "why?" ~5 times until you hit it | "Why was his check short?" → missed punch → new badge not synced → onboarding checklist skipped → HR was short-staffed that week. You've done Five Whys forever. |
| **Gap analysis** | Comparing where a process is now vs. where you want it, to find improvements | Comparing your current close (7 days) to a target close (3 days) and listing what has to change. |
| **Gut instinct** | An intuitive feeling with little or no data behind it | The "this number looks off" radar from 20 years of payroll. Valuable — but the course says verify it with data before acting. |
| **Data ecosystem** | All the elements that produce, manage, store, analyze, and share data | Your old world: the HRIS, time clocks, GL, benefits carriers, and the feeds between them. That *is* an ecosystem. |
| **People analytics** | Analyzing workforce data to improve how a company operates (aka HR analytics) | Literally your home turf — turnover, retention, comp analysis. The course's flagship case study is an HR retention project. |

### The five analytical skills (exam favorite!)
1. **Curiosity** — wanting to know why the numbers look the way they do
2. **Understanding context** — knowing what surrounds the data (season, policy change, deadline)
3. **Technical mindset** — breaking big problems into small, orderly steps
4. **Data design** — how you organize information so patterns show up
5. **Data strategy** — managing the people, processes, and tools of an analysis

### The six steps, with what happens in each
1. **Ask** — define the problem and what success looks like; question stakeholders
2. **Prepare** — identify sources, collect the data, set access rules
3. **Process** — clean it: remove duplicates, fix errors, protect confidentiality
4. **Analyze** — find patterns, trends, relationships; calculate and compare
5. **Share** — present findings with reports and visualizations, with context
6. **Act** — the business implements changes based on the insights
*(Not strictly linear — you'll loop back when you find bad data or a badly framed question. The biggest mistake is hunting for quick, easy answers.)*

## 🗣️ Teach it to a friend

A data analyst is basically a detective with a spreadsheet. There's a six-step routine: ask what
the real question is, gather the evidence (prepare), clean it up so it's trustworthy (process),
look for the pattern (analyze), explain it to the people who decide (share), and then actually
fix the thing (act). The course's big case study is an HR team figuring out why new hires quit —
they surveyed employees, found that a slow hiring process drove people away, and fixed it.
The skills it takes — curiosity, context, breaking problems into steps — aren't new to anyone
who's ever chased down a payroll discrepancy. The only real warning: don't run on gut instinct
alone; use the gut to form the question, then let the data answer it.

## 🃏 Flashcards

**Q:** Name the six steps of the data analysis process, in order.
**A:** Ask, Prepare, Process, Analyze, Share, Act.

**Q:** What are the five essential analytical skills?
**A:** Curiosity, understanding context, technical mindset, data design, data strategy.

**Q:** What's the difference between data analysis and data analytics?
**A:** Data analysis is the actual work (collecting, transforming, organizing data to draw conclusions); data analytics is the broader science of data.

**Q:** What is a root cause, and what technique finds it?
**A:** The reason a problem occurs; the Five Whys — ask "why?" repeatedly (usually ~5 times) until the underlying cause is revealed.

**Q:** What is gap analysis?
**A:** Evaluating the current state of a process against the desired state to identify opportunities for improvement.

**Q:** Why is deciding on gut instinct alone risky?
**A:** Without data to back it up, decisions can be biased and lead to costly mistakes (like the restaurant that opened in the wrong location). Blend data + business knowledge instead.

**Q:** In which step of the process do you clean data and check for duplicates and errors?
**A:** Process.

**Q:** What is people analytics?
**A:** Collecting and analyzing data about a company's workforce (also called HR or workforce analytics) to improve how the company operates.
